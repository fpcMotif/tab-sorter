# Warm Editorial — Notes

Thesis: the popup reads like an index card pulled from a library catalog — a small, ruled, ink-on-paper object that tells you exactly what's in this drawer (window) before you touch anything. Settings reads like a book's front matter: title, then chapters separated by printer's fleurons (⁂), each preference a caption under its own heading, never a modal.

Typography: Georgia stands in for Iowan Old Style for the wordmark, h1/h2, and the ⁂ asterism mark; a system sans carries every interactive label, count, and sentence of body copy — serif speaks, sans acts. Regex and shortcut keys sit in ui-monospace inside bordered "keycap" chips.

Palette: warm ivory paper (#FAF9F5) with a near-black warm ink (#211E1A); terracotta #B85630 (light) / #D97757 (dark, inverted onto dark ink text) is the only accent, reserved for the Tidy button, focus rings, and the fleuron marks — every terracotta-on-paper pairing is tuned to clear 4.5:1. A near-invisible SVG grain sits under the backdrop only, never under readable surfaces.
